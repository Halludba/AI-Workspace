# System

Canonical active source for the Recursive AI Config System.

Expected subareas:
- `runtime/` — portable runtime config/state/adapters
- `profiles/` — workflow/agent profiles such as Theme Designer and Profile Performance Auditor
- `modules/` — reusable core/extension/theme/style modules
- `schemas/` — machine validation contracts
- `engine/` — orchestration/convergence/audit implementation
- `tests/` — deterministic regression and simulation coverage
- `generators/` — PDF/reference/export generators
- `docs/` — authoritative/derived documentation sources

Do not populate this directory from an older release while the current v0.15.0 migration is pending.
